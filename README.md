## Deskripsi:
Aplikasi CRUD (Create, Read, Update, Delete) sederhana menggunakan PHP, MySQL, dan Bootstrap untuk mengelola data buku.

## Database
1. Database : perpustakaan_db
2. Tabel : buku

## Cara Menjalankan
1. Jalankan XAMPP (Apache & MySQL)
2. Import file .sql ke phpMyAdmin
3. Simpan project di:
    C:\xampp\htdocs\t4-Week10
4. Buka browser:
    http://localhost/t4-Week10
